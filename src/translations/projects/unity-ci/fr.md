Ce projet est une introduction à l'utilisation des actions GitHub pour mettre en place un projet Unity utilisant l'Intégration en Continu. Il utilise des actions déjà existantes pour mettre en place le flux de travail afin de faire tourner des tests Unity puis de générer un build pour différentes plateformes.
